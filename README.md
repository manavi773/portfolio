# Personal Portfolio Website

A responsive, interactive personal portfolio website built as part of the **Day 2: Web Fundamentals** assignment.

---

## 📌 Project Overview
This website showcases my background in **Artificial Intelligence & Machine Learning (AIML)**, foundational programming skills, and recent projects. It is designed to be fully responsive and accessible across different screen sizes.

---

## ✨ Features
* **Semantic HTML5:** Clean, accessible structure with dedicated sections for About, Education, Skills, Projects, and Contact.
* **Modern CSS:**
  * Custom CSS variables for scalable color schemes.
  * Flexbox layouts for the navigation bar, hero header, skills grid, and project cards.
  * Media queries for full mobile responsiveness.
* **Interactive JavaScript:**
  * **Dark / Light Mode Toggle:** Smooth theme switcher between dark and light themes.
  * **Dynamic Contact Form:** Form validation and interactive confirmation feedback upon submission.

---

## 🛠️ Technologies Used
* **HTML5**
* **CSS3 (Flexbox & Responsive Media Queries)**
* **JavaScript (DOM Manipulation & Event Listeners)**
